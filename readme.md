The goal of this repository is not simply to collect solutions, but to develop the ability to reason about problems, design solutions, analyze complexity, and implement them independently.

## 🎯 Goals

* Strengthen problem-solving and algorithmic thinking
* Build a strong foundation in Data Structures & Algorithms
* Practice writing clean and efficient Python

## ⏱️ Complexity

For each problem, I aim to understand:

* **Time Complexity**
* **Space Complexity**
* Why the algorithm has that complexity
* Possible optimizations and trade-offs

Example:

```text
Algorithm: Binary Search

Time:  O(log n)
Space: O(1)
```

Understanding *why* an algorithm is `O(log n)` is more important to me than simply knowing that it is.

## 🧩 Problem-Solving Approach

For each problem, I try to follow this process:

```text
1. Understand the problem
        ↓
2. Work through examples
        ↓
3. Solve it on paper
        ↓
4. Identify the data structure / pattern
        ↓
5. Write the algorithm
        ↓
6. Implement it in Python
        ↓
7. Test edge cases
        ↓
8. Analyze time & space complexity
        ↓
9. Look for improvements
```

The emphasis is on **thinking before coding**.
